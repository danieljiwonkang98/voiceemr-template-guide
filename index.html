세 가지 표시

[1:N]

문장 빈칸

소견처럼 문장 전체를 말할 자리입니다. 버튼을 누를 때마다 [1:], [2:] 번호가 생깁니다. 영어로 말하면 첫 글자가 대문자가 됩니다.

말하기“1번” 하고 문장을 말합니다
{1:n}

짧은 값 빈칸

크기, 숫자, 한 단어처럼 문장 안에 짧은 값만 넣을 자리입니다. 버튼을 누르면 {1:}, {2:} 가 생깁니다.

말하기“1번” 하고 값만 말합니다
≪word≫

선택지 (있어도 되고 없어도 되는 부분)

≪ ≫ 로 감싼 부분은 그 안의 번호를 부르면 남고, 부르지 않으면 통째로 사라집니다. 그래서 선택지 안에는 꼭 번호 칸 {n:} 또는 [n:] 이 하나 있어야 합니다.

예: ≪{1:Rt}≫ ≪{2:Lt}≫ → “1번” 이라고만 말하면 Rt 만 남습니다.

말하기남기고 싶은 선택지의 번호를 부릅니다

N 과 n 은 “번호”라는 뜻입니다. 클릭할 때마다 1, 2, 3으로 늘어납니다. 칸을 옮겼다면 앱의 정렬을 누르면 번호가 다시 맞춰집니다.

≪Rt≫ ≪Lt≫ 처럼 안에 번호 칸이 없으면 고를 방법이 없어서 둘 다 사라집니다. 선택지 하나마다 번호 칸을 하나씩 넣어 주세요.

이것만 기억하세요

{1:} → “1번” 하고 짧은 값만 말하기
[2:] → “2번” 하고 문장 말하기
≪{1:Rt}≫ ≪{2:Lt}≫ → 남길 쪽의 번호만 부르기. 부르지 않은 선택지는 사라집니다
선택지 안에는 번호 칸이 꼭 하나 → 번호 칸이 없는 선택지는 고를 수 없습니다

자주 생기는 문제

붙였는데 선택지가 전부 사라졌어요

선택지 안의 번호를 부르지 않았거나, 선택지 안에 번호 칸이 없는 템플릿입니다. 화면에서 선택지가 초록색으로 바뀌었는지 먼저 확인하세요. 초록색이 안 되면 그 선택지는 붙일 때 사라집니다.

Rt 와 Lt 가 둘 다 남았어요

“1번” 과 “2번” 을 둘 다 불렀기 때문입니다. 한 번 초록색이 된 선택지는 그대로 남으니, 잘못 골랐으면 지우기 버튼으로 비우고 템플릿을 다시 부르세요.

번호를 불렀는데 값이 옆 칸에 들어갔어요

번호와 값 사이를 조금 띄어 말하세요. “3번” 하고 화면의 커서가 그 칸으로 옮겨진 뒤에 값을 말하면 정확히 들어갑니다.

“US OF KNEE : Lt” 처럼 빈칸이 두 개 보여요

앞쪽 선택지(Rt)가 지워지면서 남은 빈칸입니다. 내용에는 문제가 없고, EMR 에서 그대로 두어도 됩니다.
